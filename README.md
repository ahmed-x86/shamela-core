# Shamela Core

A community-driven wrapper and core enhancement for the Shamela Library software.

## Description

Shamela Core is an open-source project dedicated to bringing the renowned Al-Shamela Library to the Linux ecosystem with a "native" feel. This project focuses on wrapping the core engine to ensure better compatibility, performance, and ease of installation on modern Linux distributions, starting with Arch Linux.

## Installation (Arch Linux)

Currently, the project provides an automated installation script specifically for Arch Linux. You can install it directly using the following command:
```
curl -s https://raw.githubusercontent.com/ahmed-x86/shamela-core/refs/heads/main/install-arch.sh | bash
```
## Uninstallation

To remove the program and all its associated system files, use the uninstallation script:
```
curl -s https://raw.githubusercontent.com/ahmed-x86/shamela-core/refs/heads/main/uninstall-arch.sh | bash
```
