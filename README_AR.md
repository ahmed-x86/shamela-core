# Shamela Core

تغليف مجتمعي وتحسين للنواة لبرنامج المكتبة الشاملة.

## نبذة عن المشروع

Shamela Core هو مشروع مفتوح المصدر مخصص لجلب المكتبة الشاملة الشهيرة إلى نظام لينكس بطابع "أصلي" (native). يركز هذا المشروع على تغليف المحرك الأساسي لضمان توافق أفضل، أداء أقوى، وسهولة في التثبيت على توزيعات لينكس الحديثة، بدءاً من آرتش لينكس (Arch Linux).

## التثبيت (آرتش لينكس)

حالياً، يوفر المشروع سكربت تثبيت تلقائي مخصص لتوزيعة آرتش لينكس. يمكنك تثبيته مباشرة باستخدام الأمر التالي:
```
curl -s https://raw.githubusercontent.com/ahmed-x86/shamela-core/refs/heads/main/install-arch.sh | bash
```
## إزالة التثبيت

لإزالة البرنامج وكافة ملفات النظام المرتبطة به، استخدم سكربت إزالة التثبيت:
```
curl -s https://raw.githubusercontent.com/ahmed-x86/shamela-core/refs/heads/main/uninstall-arch.sh| bash
```
## خطة العمل (Roadmap)

نحن نعمل على توسيع نطاق المشروع ليشمل:

* [ ] دعم التوزيعات الكبرى الأخرى (ديببيان، فيدورا، إلخ).
* [ ] دعم معماريات معالجات مختلفة (ARM64, RISC-V).
* [ ] تحسينات في الأداء وتطوير واجهة مستخدم "أصلية".
